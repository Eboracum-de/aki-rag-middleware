# Support

SunaQ is currently a public-beta open-source project.

- Bugs and reproducible operational problems: use GitHub Issues.
- Security vulnerabilities: follow `SECURITY.md`.
- Architecture/feature discussions: open an issue with the use case and deployment profile.

No SLA is currently offered. Tested deployment combinations and known limitations are documented in `docs/BETA-OPERATIONS.md` and `docs/KNOWN-LIMITATIONS.md`. Questions can be sent to `rag@eboracum.de`.
