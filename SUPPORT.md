# Support

AKI RAG Middleware is currently a public-beta, maintainer-led open-source project.

- Bugs and reproducible operational problems: use GitHub Issues.
- Security vulnerabilities: follow `SECURITY.md`.
- Architecture/feature discussions: open an issue with the use case and deployment profile.

Public availability does not imply an SLA or guaranteed response time. Tested deployment combinations and known limitations are documented in `docs/BETA-OPERATIONS.md` and `docs/KNOWN-LIMITATIONS.md`.
